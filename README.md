# Aural Studio 听觉练习室

ABRSM 钢琴五级现场考试的听觉备考网站。默认简体中文，可以切换到英文。手机和电脑使用同一套练习，网站可以直接作为静态文件运行。

## GitHub Pages

发布后，手机和电脑都可以访问[在线练习室](https://db-ol.github.io/grade5-aural/)。首次使用麦克风时，请允许浏览器访问麦克风。

仓库使用 `main` 分支的根目录作为 Pages 发布源。推送后由 GitHub Pages 自动更新网站，无需安装依赖或编译。

## 电脑和手机试用

电脑可以直接用浏览器打开 `index.html`。要在本机使用离线缓存，或让同一无线网络里的手机访问，请在 Mac 终端运行以下命令。

```sh
cd ~/projects/piano/aural
python3 -m http.server 8766
```

电脑访问 [本地练习室](http://localhost:8766)。在同一网络的 iPhone 上，打开 Mac 的局域网地址并加上端口 `8766`。例如，Mac 的网络地址为 `192.168.1.20` 时，手机打开 `http://192.168.1.20:8766/`。终端按 `Control+C` 停止服务。

局域网 HTTP 支持播放、视唱自评、音乐听辨和屏幕拍击。手机使用麦克风和离线缓存需要受信任的 HTTPS 地址。电脑使用 `localhost` 即可请求麦克风权限。[浏览器麦克风权限说明](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)

通过 HTTPS 首次访问后，等待页脚显示“已可离线练习”。iPhone 可在 Safari 的分享菜单中选择“添加到主屏幕”。网站在本机生成声音，字体与插画也随页面缓存。离线使用期间请保留浏览器的网站数据。

## 练什么

| 环节 | 作答方式 | 复习方式 |
| --- | --- | --- |
| A 旋律记忆 | 听主和弦、起音和两小节预备拍，再听两遍旋律，凭记忆唱出或弹出。 | 使用麦克风查看逐音核对和节奏反馈，或听示范自行对照。 |
| B 六音视唱 | 选择高音谱号或低音谱号，听主和弦与起音，按自己的速度演唱。 | 检查每个音的音高，听单音示范，练习不同调号。 |
| C（i）音乐听辨 | 听前先看考查方向，辨别音乐特征以及作品的风格和时期。 | 八首原创短曲覆盖四种时期风格，讲解指出旋律、伴奏和表现手法中的线索。 |
| C（ii）节奏与拍子 | 听两遍单声部摘录，拍回音符的节奏，再判断每小节有几拍。 | 可以用麦克风拍手、触屏点拍或键盘空格作答，分别查看节奏与拍子反馈。 |

模拟测试依次完成四个环节。两道 C 项使用同一首曲子，全部作答后再看讲解。范围依据两版钢琴现场考试大纲的印刷页第 49 页。[2025 至 2026 年大纲](https://www.abrsm.org/sites/default/files/2024-06/Piano%202025%20%26%202026%20Prac%20syllabus%2020240524_access.pdf)　[2027 至 2028 年大纲](https://www.abrsm.org/sites/default/files/2026-06/Piano%20Practical%20Grades%20Qualification%20Specification%202027%20%26%202028.pdf#page=50)

## 反馈与记录

麦克风分析在本机完成。演唱时选择舒适的八度，每个音用一个独立的音节。在支持录音的浏览器中，提交后可以交替听自己的演唱或拍手录音与示范。背景声、回声和过于连贯的同音可能影响识别。百分比用于练习反馈，考试分数由考官根据整体表现评定。

浏览器保留最近 120 次已完成的练习，记录自评或自动反馈、当时的题目和视唱谱号。可从记录中原样重练一道题或一套模拟，也可以换一道同类型的新题。声音样本不会写入历史或上传。手机与电脑各自保存自己的记录。

## 自动测试

```sh
node --test tests/*.test.mjs
```

测试覆盖旋律与视唱的出题范围、音频播放顺序、两种谱号、合成音高与拍手检测、整套模拟流程、原题重现和离线缓存。实体设备的麦克风效果需在使用环境中核对。
