# Aural Studio 听觉练习室

ABRSM 钢琴五级、七级和八级现场考试的听觉备考网站。默认简体中文，可以切换到英文。手机和电脑使用同一套练习，网站可以直接作为静态文件运行。

## GitHub Pages

手机和电脑都可以访问[在线练习室](https://db-ol.github.io/aural-studio/)。首次使用麦克风时，请允许浏览器访问麦克风。

仓库使用 `main` 分支的根目录作为 Pages 发布源。推送后由 GitHub Pages 自动更新网站，无需安装依赖或编译。

## 电脑和手机试用

电脑可以直接用浏览器打开 `index.html`。要在本机使用离线缓存，或让同一无线网络里的手机访问，请在 Mac 终端运行以下命令。

```sh
cd ~/projects/piano/aural
python3 -m http.server 8766
```

电脑访问 [本地练习室](http://localhost:8766)。在同一网络的 iPhone 上，打开 Mac 的局域网地址并加上端口 `8766`。例如，Mac 的网络地址为 `192.168.1.20` 时，手机打开 `http://192.168.1.20:8766/`。终端按 `Control+C` 停止服务。

局域网 HTTP 支持播放、视唱自评、音乐听辨和屏幕拍击。手机使用麦克风和离线缓存需要受信任的 HTTPS 地址。电脑使用 `localhost` 即可请求麦克风权限。[浏览器麦克风权限说明](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)

通过 HTTPS 首次访问后，等待页脚显示“已可离线练习”。iPhone 可在 Safari 的分享菜单中选择“添加到主屏幕”。网站在本机生成声音，字体与插画也随页面缓存。离线使用期间请保留浏览器的网站数据。

## 唱完怎样看音准

1. 进入所选级别的旋律记忆或视唱专项，播放题目。视唱可以选择高音谱号或低音谱号。
2. 在开唱前点“录音并检查音准”，首次使用时允许麦克风权限。等录音就绪，每个音用一个独立的音节唱出。七级和八级的视唱有另一个声部伴奏，戴耳机听钢琴，在两小节预备拍后进入。
3. 点“完成演唱并检查”。专项练习立即显示唱准了几个音，并逐行列出目标音、检测音、音分偏差和“准确、偏高、偏低、漏音”。点目标音可以听标准音。支持录音回放的浏览器也能回听刚唱的一遍。模拟测试在全部作答后显示结果。

演唱可以整体移到舒适的八度。逐音表按同一个八度对齐，目标音上下 50 音分以内计作准确。背景声和钢琴外放可能影响检测。如果选择自行评分，可以听示范与自己的演唱对照。练习得分用于找出需要再练的音，现场考试由考官整体评定。

## 各级练习

首页、模拟测试和练习记录都可以切换级别。每个级别既能按题型专项练习，也能按考试顺序做整套模拟。题目和钢琴示范均为本站练习素材。

| 级别 | 旋律与视唱 | 和声与音乐听辨 |
| --- | --- | --- |
| 五级 | A 听两遍后凭记忆唱出或弹出旋律。B 看谱唱六个音。 | C（i）辨别音乐特征及风格时期。C（ii）拍回同曲片段，判断二拍、三拍或四拍。 |
| 七级 | A 从两个声部中记住低声部。B 钢琴弹低声部，考生看谱唱高声部。 | C 辨终止式、两个原位和弦及大调转调。D 回答两项音乐特征问题，再拍回同曲片段，拍子选项包括八六拍。 |
| 八级 | A（i）从三个声部中记住最低声部。B 钢琴弹高声部，考生看谱唱低声部。 | A（ii）和 A（iii）听续句，辨终止式及三个和弦与转位。C 分别听大调和小调的转调。D 口头或书面描述音乐，与参考要点对照并自评。 |

练习按 ABRSM 钢琴现场考试大纲设计。五级见印刷页第 49 页，七级与八级见第 51 页和第 52 页。[2025 至 2026 年大纲](https://www.abrsm.org/sites/default/files/2024-06/Piano%202025%20%26%202026%20Prac%20syllabus%2020240524_access.pdf#page=52)　[2027 至 2028 年大纲](https://www.abrsm.org/sites/default/files/2026-06/Piano%20Practical%20Grades%20Qualification%20Specification%202027%20%26%202028.pdf#page=52)

## 练习记录

浏览器为每个级别保留最近 120 次已完成的练习。打开记录可以回顾音准或听辨结果，也可以按当时的题目和谱号再练一次。原有的五级记录仍可查阅。麦克风分析在本机完成，录音只供当次回听。声音样本不会写入历史或上传。手机和电脑各自保存练习记录。

## 自动测试

```sh
node --test tests/*.test.mjs
```

测试覆盖旋律与视唱的出题范围、音频播放顺序、两种谱号、合成音高与拍手检测、整套模拟流程、原题重现和离线缓存。实体设备的麦克风效果需在使用环境中核对。
